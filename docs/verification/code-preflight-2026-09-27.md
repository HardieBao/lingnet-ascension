- Runner手动preflight和装备后自动预检共用代码检查路径。固定基线缺package/lock/可信CI配置时失败关闭，不执行自定义命令或跳过检查。

- 预检失败不补模型额度、不延租、不发游戏奖励。自动预检异常会沿原检查点安全规则尝试保留产物，不保存原始模型会话。
