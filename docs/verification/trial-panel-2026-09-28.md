# 渡劫侧栏：本地接线与浏览器验证

日期：2026-09-28。本轮仅接上已存在的渡劫公开API，不修改资格、冻结、成功扣费、未成功全额解冻或新认领重试规则。新增界面尚未提交、推送或部署，不证明真人渡劫或正式MVP完成。

## 实现与边界

- `TrialPanel`从原境界天梯打开，复用现有Sheet、AlertDialog、Button、输入和森林薄荷色样式；凡人到炼气仍沿原免费突破入口。
- 只从`GET /api/trials`读取本人资格、有效候选和最近最多30条记录；不输入任意认领、不生成推荐任务或虚构空记录。
- 开始、结算、退出使用已有POST接口，先确认金额、时限和后果；退出理由去空白后1–500字。请求互斥、15秒客户端超时；失败/不确定时不自动重发、不乐观修改余额与境界，保留确认原因并要求读回核对。
- 关闭侧栏不取消渡劫；不提供客户端“确认平台故障”权限，不改变服务端所有权、同源或正式成果校验。
- Superdesign保存的trial-panel目标、10个安全上下文及指纹核对通过，实际草案仍版本1；沿此前已确认的现有样式路径实施，没有新生成、上传源码、覆盖设计缓存或花费生成额度。草案的合成余额没有带入产品。

## 本地合成浏览器环境

`manual-trial-panel.mjs`启动独立、只监听127.0.0.1的Node/Miniflare/D1环境；使用实际构建的Worker和客户端文件，拒绝外部服务。合成账号与任务明确标记“非真实贡献”，签名只用固定测试秘密，不读私密环境配置或生产Cookie。fixture路由仅属于该独立脚本，不进入站点Worker。

- 初次种子复验说明不足数据库20字要求，启动退出1。仅改为足够长的合成说明，未放宽数据库约束。
- 首次浏览器仅有裸HTML，点击无效。实际probe发现Windows资源清单33条反斜杠路径、0条网页正斜杠路径；将清单统一为网页路径后，CSS/JS正常加载，背景实际为rgb(7,17,19)，侧栏可打开。没有据此修改业务规则。
- 首轮鼠标选择未自动滚动到远离视口的境界入口；后续使用显式焦点与Enter验证键盘。独立鼠标回放时，将入口滚到视口后仍需等待原有平滑滚动稳定；边界框确认y=479.578125后，点击成功打开侧栏、确认开始POST201并冻结500。没有为工具操作问题修改业务规则。

## 已取得行为证据

1. 筑基：浏览器确认开始后POST201，可用游戏Token3000→2500、冻结500；关闭再打开仍同一活动记录、未再次冻结。空退出理由禁用确认，填写合成理由后POST200，余额恢复3000/冻结0，保留退出记录和原认领。
2. 资格不足：功德49/50显示“功德还需1”，本人候选仍可查看，但开始按钮禁用；该账号无其他账号历史或新渡劫记录。
3. 金丹：显示5000修为、200功德、10正式成果与1已采纳复验；确认开始冻结2000，可用余额1000。无本次正式成果时结算POST409，确认框保持打开、显示服务端原因，不显示突破成功。仅在本地fixture加入合成正式成果后，结算POST200，进入金丹、冻结0、可用余额仍1000；没有重复扣除费用。
4. 界面回归修正：开始资格的“还需Token”不再用于已冻结的活动渡劫；费用提示明确无需再次支付。原RealmActions到金丹时早返回改变组件位置，导致侧栏重新挂载关闭；固定侧栏位置后，同一结算回放从panels=0变为panels=1、确认框0，最新金丹记录持续可见。空理由改为准确的填写提示。
5. 320px：侧栏实测宽320、确认框288，二者无横向溢出；退出输入字体16px。Tab焦点保持在活动浮层，取消为确认框初始焦点；Esc后面板0，焦点回到“渡劫资格与记录”。减少动态效果开启时面板animationName=none。
6. 凡人空状态：无专属候选和历史，显示实际修为/功德/正式成果缺项与免费炼气入口说明，不造任务或成功记录。
7. 断网：读回失败不显示默认0或假空历史，开始/结算无可用数据；修正后使用中文错误，不暴露原始fetch异常。恢复网络重新读回仍2500可用/500冻结，断网没有退款、扣费或自动重试。
8. 独立鼠标与触摸仿真：鼠标打开/确认开始后2500可用、500冻结。工具的iPhone12设置仅改变390px视口，navigator.maxTouchPoints实际为0，未冒称触摸已开启；按[Chrome官方协议定义](https://github.com/ChromeDevTools/devtools-protocol/blob/master/json/browser_protocol.json)，仅连接本次本地合成页，启用触摸并发送原生touchStart/touchEnd。发送期间maxTouchPoints=1，触摸打开退出确认；填写合成理由后再触摸确认，POST200、余额3000/冻结0，保留退出历史。不是JS直接调用按钮，不读取Cookie，不计真机或真人验收。

这些观察来自真实浏览器、实际公开HTTP接口和隔离合成D1，不来自替换内部业务函数；合成复核/正式成果仅是测试前置，不能计入真人独立复验、25社区成果、两类真实渡劫或三周版本。
