本附录依据实际源码与本地合成截图记录局部实现，不替代全局设计规范。本次没有新增全局设计 token，因此保留根目录 `DESIGN.md` 和 `.impeccable/design.json`，不因局部控件、断点或状态文案重新生成全局体系。

## Colors

筛选区继承既有暗青底面、浅色正文、薄荷主操作和薄边界。输入底面、边界、正文、辅助文字、主按钮及其文字直接使用现有语义变量，没有创建新的品牌辅色或局部色板。主按钮悬停色也沿用已有的浅薄荷值。

状态均有明确文字。列表用「可认领」「已认领」「冻结待复核」「待合入」「已完成」「等待前置」「待发布」「门槛未达」表达任务格状态；颜色不能代替这些含义。无效条件提示沿用平台已有的温暖提示色。

## Typography

平台继续使用 Arial、Helvetica、sans-serif 字体栈。筛选标签（14px）、输入与选择文字（16px）、辅助说明（14px，行高 1.7）来自当前实现。未增加外部字体或展示字体。

本轮静态检测器退出 1，仅报告既有 Arial 字体 warning；这不是新增差异。它不构成此次筛选扩展的换字体理由，不能说检测器零警告，也不作为全站字体体系已经完成设计确认的证据。

## Layout

筛选区位于宗门悬赏标题与结果表格之间。桌面采用三列等宽控件网格（间距 16px），五项条件与操作区形成两行；视口宽度不超过 600px 时改为单列。标签与控件保持垂直对应，操作区可以换行。

页面壳继承现有三栏布局：导航（250px）、可伸缩主区和详情（310px）。不超过 1200px 时继承双栏及主区下方详情布局；不超过 760px 时继承纵向堆叠与横向导航。本轮未改变这些全局布局规则。

悬赏表格继续保留六列及横向滚动容器，最小表格宽度为 700px；窄屏通过容器滚动查看后续字段。模型 Token 预算与游戏奖励使用独立列，不把两个数值合并为同一种额度。

## Elevation & Depth

局部筛选与空结果通过底面、描边、文字层级和留白区分，没有新增阴影、图片、图表、动效或抬升卡片。现有页面元素与已有依赖保持原状；本次没有引入组件库。

## Shapes

筛选输入、选择和主按钮继承现有平台操作控件的轻微圆角（3px）与细边界（1px）。筛选控件及应用、清空入口的最小高度为 44px；这些值仅描述本次筛选区，不扩展为其他页面所有按钮的统一规定。

## Components

### 五项组合筛选

使用原生文本输入、选择与数字输入，均有可见标签。表单以 GET 提交到 `/`，条件保存在 URL；刷新、分享当前地址及浏览器导航可以保留已提交的筛选状态。选择结果行时保留五项条件，并增加所选任务编号。

| 控件 | URL 参数 | 实际规则 |
| --- | --- | --- |
| 编号或标题 | `q` | 去除首尾空白，匹配任务编号或标题；最多 80 字 |
| 品阶 | `rank` | 黄阶、玄阶、地阶、天阶，或全部 |
| 任务线 | `branch` | 从已有任务线生成选项，或全部 |
| 任务格状态 | `status` | 使用已有任务、占位、前置与门槛数据计算的状态，或全部 |
| 最高模型 Token | `budget` | 非负整数上限；有预算记录且不超过上限的任务才匹配 |

五项条件同时生效。预算未记录时显示「未记录」，不伪装成零；设置预算上限后不纳入此类任务。预算说明明确模型 Token 不等于游戏灵石或现金价格。

「可认领」是任务格状态，仍须通过账号门槛、认领席位和押金余额等服务端核验。R1 文案修订后的说明已将这些条件写明，不将列表状态表述为当前用户已获得认领许可。

无效条件不回退为全部结果：显示提示并返回空结果，提供重新选择或清空入口。字段、按钮和筛选区链接的键盘焦点使用薄荷轮廓（2px，外偏移 3px），不只依赖悬停色。

### 空结果与本人在途入口

结果数量显示为当前匹配数与任务总数。没有匹配时，表格提供调整条件与「清空筛选」入口；详情区显示「先选择一张悬赏」，不显示其他悬赏的认领操作。

登录者有在途记录时，「我的在途悬赏（含冻结）」仍显示在表格上方。点击任务编号清除筛选并查看原认领，不新建认领。该入口在合成空结果截图中仍可见，帮助用户找回被筛选条件隐藏的本人记录。

### 冻结与满席

冻结记录计入在途席位，并以「冻结待复核」展示。操作区先展示冻结说明，冻结期间不提供重跑、提交或主动释放入口；原租约和押金按复核规则处理。该状态只说明等待独立复核，不宣称成果已正式接受或结算。

满席提示指向「我的在途悬赏」查看占用记录，并明确冻结任务须等待独立复核、不能主动释放；没有将释放冻结记录写成腾出席位的方法。

## Do's and Don'ts

- **Do** 继承既有暗青操作页和原生控件，保持可见标签、16px 输入文字及筛选区清晰键盘焦点。
- **Do** 让 URL 表达已提交的五项条件，让空结果保留清空和本人在途入口。
- **Do** 区分任务格状态、本人认领许可、模型预算和游戏奖励；最终认领以服务端核验为准。
- **Do** 保留冻结占位与等待独立复核的事实，准确显示当前允许的入口。
- **Don't** 从本次 600px 断点、3px 圆角、合成截图或既有 Arial warning 推导新的全局设计体系。
- **Don't** 把助手审查、截图或通过的自动检查表述为正式 MVP、COR-003 完整验收、真人贡献或生产放行。认领确认与真实验收仍未完成。
