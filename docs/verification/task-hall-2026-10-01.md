## 行为与边界

五项 GET 条件同时生效：编号/标题、品阶、任务线、任务格状态、最高模型 Token。状态来自任务契约、正式前置、当前占位和境界/功德要求，不靠客户端改变任务。选择结果行保留条件；清空时控件与结果同步。无效条件返回空结果和恢复提示，不静默放宽为全部任务。

预算与游戏奖励使用不同列；缺少预算记录显示「未记录」，不能当作零进入预算上限筛选。列表的任务格状态不等于本人已满足席位或押金条件，最终仍以认领 API 为准。当前没有可靠的耗时字段，未虚构耗时筛选；模型仍由既有认领契约锁定。

冻结记录纳入本人席位和任务占位。本人、另一合成账号与匿名访客均可看到冻结说明，但不能重跑、提交、主动释放或重新认领。满席提示指向原认领并说明独立复核，不能建议释放冻结记录腾出席位。没有修改冻结期限、押金或奖励。

空结果不渲染另一张悬赏的详情操作。登录者仍可从本人在途入口清除筛选、查看原认领；这是导航，不会创建新认领。
